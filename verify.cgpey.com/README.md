# verify.cgpey.com

This directory was added to provide a starter scaffold for `verify.cgpey.com`.

## Files

- `index.html` – root landing page with links to verification services
- `pan/index.html` – PAN verification page
- `script.js` – PAN verification interaction logic (used by PAN page)
- `style.css` – shared styling for PAN and voter ID pages
- `voter-id/index.html` – separate voter ID verification page
- `voter-id/script.js` – voter ID verification interaction logic

## Links

- Home page links to PAN and voter ID pages
- PAN page links to Home and voter ID pages
- Voter ID page links to Home and PAN pages
