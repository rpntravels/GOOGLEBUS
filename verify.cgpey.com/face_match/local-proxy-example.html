Face Match Local Proxy Example

This example posts image files to /api/v1/verify/face_match on the same site.

If you open this file directly from disk, it falls back to http://localhost:3000.



    
fetch((window.location.protocol === 'file:' ? 'http://localhost:3000' : '') + '/api/v1/verify/face_match', {
  method: 'POST',
  body: formData
});
